The dashboard your Palworld server deserves.

Palcon is a self-hosted console for Palworld dedicated servers — live map, player pals and inventories, paldex records, breeding math, backups and one-click repair. One Go binary. Your hardware. Your data.

palcon.local — live map

Everything your world is up to, in one place.

Palcon talks to the server over its REST API (with automatic RCON fallback) and reads the world save directly — so it can show you things no admin command can.

Live map

See your archipelago breathe.

Players plotted on the real world map as they roam, with pan, zoom and click-to-focus — plus every guild base and where offline players last logged off.

  • Main map and the Tree area
  • Toggleable layers: fast travel, watchtowers, dungeons, alpha & predator spawns
  • Falls back to last-saved positions when the server sleeps
Player pals

Every party, palbox and base — from the save itself.

Real names, artwork, IVs, passives and equipped skills for every pal on the server, parsed straight from Level.sav. Search by name, species or passive; filter by IV floor.

  • Party, palbox, storage and base pals per player
  • Alpha, lucky and gender at a glance
  • Re-parses only after the game autosaves
Inventory

Their bags, slot for slot.

The save keeps where every item sits, so Palcon draws the bag the way the game does — gaps and all. A backpack reading 45 / 45 is the difference between carrying a lot and not being able to pick anything up.

  • Weapons, gear, accessories and food racked by slot, with durability
  • How each player spent their stat points — the build behind the level
  • Search highlights matches in place, so you see where in the bag they are
Storage search

Where is all the cement?

Search every chest, box, feed trough and furnace on the server at once. The answer isn't just a number — it's the split: how much sits at which base, and which box to open when you get there.

  • Chests named and pictured the way the game does — a "Refined Metal Chest" is one you can spot
  • Guild chests and work-station hoppers included; bases named by the landmark they sit near
  • Treasure chests out in the world stay hidden behind a spoiler prompt
Paldex & records

Your server's record book.

Per-player paldex completion with a "what's missing" browser, and server-wide records: best-IV pals, capture leaders, alpha and lucky tallies, one-of-a-kind catches.

  • Registered species from each player's own save record
  • Server completion bar for the group goal
  • Bragging rights, quantified
Breeding calculators

Breeding math that knows your box.

Child species, reverse lookup, talent targets and passive-inheritance odds — computed against the pals actually on your server, not a hypothetical box.

  • Shortest route from your pals to the one you want
  • Exact-set and with-extras passive odds, expected egg counts
  • Community-measured rates, credited
Anywhere

Pocket-sized server care.

The whole console is responsive and installable as a PWA — check who's online from the sofa, save the world from the bus, restart from anywhere you'd rather not be.

  • Bottom-bar navigation tuned for thumbs
  • Add to home screen, no app store
  • Same permissions, same audit trail

And the unglamorous parts, handled.

The features you stop noticing because things just keep working.

SteamCMD repair

Clear a corrupted update cache and revalidate from the dashboard, transcript streaming live. No shell required.

Save backups

Scheduled zip snapshots with retention, mid-write detection and skip-when-unchanged. Restores stay manual, by design.

Scheduled restarts

Weekday and time schedules with in-game warning broadcasts, and a world save before every restart.

Crash watchdog

Revives error exits with a cooldown and a three-strikes stand-down, so a crash loop gets a human, not a fourth restart.

Discord notifications

Server down and back online, joins and leaves, restart notices — each individually toggleable per server.

Users & permissions

Give players accounts with only the rights you want them to have. Revocations apply immediately.

Public status page

An opt-in, unauthenticated page behind an unguessable link — online, player count, next restart. No player names.

palagent sidecar

An optional per-server agent that replaces every bind mount, and in supervisor mode runs the game itself.

Trust

Built to be trusted with your world.

A management tool holds the keys to hundreds of hours of your friends' play time. Palcon is designed so the worst case is always boring.

Saves are read-only — structurally.

The save mount is read-only and the newer save format is unwrapped with a decompress-only library: there is no code path that can write a save. Settings edits go to a separate config mount, written atomically.

No Docker socket.

Power control goes through a scoped proxy that allows exactly inspect · start · stop · restart — no creating containers, no mounts, no exec. A compromised Palcon can bounce your game server, and that's all.

Private by the switch, not the menu.

Any view — map, pals, inventory, paldex, guilds, calculators — can be turned off for a server, and any single player can be withheld from the pals, inventory or map data while everyone else stays visible. The API refuses it too, so hiding a page actually hides the data behind it. Admins keep their own view, so honouring a request doesn't cost you moderation.

Your data stays home.

Fully self-hosted: one SQLite file on your own disk. Stored server credentials are encrypted at rest, and nothing talks to the internet except the Discord webhook you configure — if you configure one.

Up and running in five minutes.

  1. Make a folder for Palcon's data

    One dataset or directory — it holds the single palcon.db file.

  2. Deploy the container

    Paste the compose spec into TrueNAS's Custom App, Portainer, or plain docker compose up.

  3. Sign in and add your server

    Host, ports and passwords from PalWorldSettings.ini. Optional extras — container name for power control, save path for pals — light up on their own.

docker-compose.yml 
services:
  palcon:
    image: ghcr.io/safwyls/palcon:latest
    ports:
      - 30801:8080
    environment:
      JWT_SECRET: <random string>
      ENCRYPTION_KEY: <exactly 32 characters>
      ADMIN_USERNAME: admin
      ADMIN_PASSWORD: <first-login password>
      # optional — enables start/stop/restart
      DOCKER_HOST: tcp://docker-proxy:2375
    volumes:
      - /mnt/tank/apps/palcon:/data
      # optional — enables pals & guilds (read-only!)
      - /path/to/SaveGames/0/<world>:/saves/myserver:ro
    restart: unless-stopped

  # optional — scoped proxy for power control
  docker-proxy:
    image: ghcr.io/tecnativa/docker-socket-proxy:latest
    environment: { CONTAINERS: 1, POST: 1 }
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock:ro
    restart: unless-stopped
